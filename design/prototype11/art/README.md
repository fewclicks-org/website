# Art credits

The flat item, plant and sticker pictures in `tw/` are **Twemoji** graphics
(from the `@twemoji/svg` package), copyright Twitter, Inc. and other contributors,
licensed under **CC-BY 4.0**: https://creativecommons.org/licenses/by/4.0/

The files are copied into this site (never hot-linked) and some are renamed
(for example `deciduous.svg` is 🌳, `evergreen.svg` is 🌲). Devices that Twemoji
does not have (tap, tank, bore pumps, sprinkler, watering can, fan, wind sock,
clock, spinner, dice) are drawn in code in `js/flatart.js` in the same flat style.
