# Fonts

Self-hosted copies (latin subset, woff2) from the npm `@fontsource/*` packages so the whiteboard never contacts a font CDN.

All fonts are licensed under the SIL Open Font License 1.1: Rubik Bubbles, Bungee, Monoton, Pacifico, Permanent Marker, Press Start 2P, Bebas Neue, Caveat, Lobster, Rampart One, Righteous and Inter.
